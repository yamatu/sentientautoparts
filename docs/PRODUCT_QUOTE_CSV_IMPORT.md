# 报价 CSV 导入

后台产品页的「批量导入」现在支持报价 CSV。表头可以使用中文或英文：

```csv
品牌,型号,价格,交期
ABB,3ABD00045441-D,"$4,833",3-4 DAYS
Siemens,6ES7-TEST,,
```

导入规则：

- 型号会规范化后作为 SKU 匹配，文件内重复型号只处理一次，后出现的非空价格、交期和品牌会合并到第一条。
- 网站已有 SKU 不会重复创建；非空价格和交期会更新，空价格不会清空网站已有价格。
- 网站没有的型号会创建为启用产品。价格为空、`N/A`、`-`、`Contact for quote`、`询价` 或 `待报价` 时，产品会进入联系询价状态。
- 价格带美元符号、千分位或 `USD` 均可识别；导入完成后页面会显示新增、更新、跳过和失败数量。

PayPal 退款配置需要在后端设置 `SETTINGS_ENCRYPTION_KEY`（32 字节随机值）。后台 PayPal 页面只显示 Secret 是否已配置，Secret 会在服务器端加密保存，不会返回到浏览器。
